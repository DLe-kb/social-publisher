# 平台字段与素材规格

以下规则来自平台官方资料和创作者后台界面截图。标为“界面观察”的字段应在真实账号页面再次确认。

| 平台 | 文案限制 | 视频与封面 | 其他字段 |
| --- | --- | --- | --- |
| 抖音 | 标题 30 字；描述区 1000 字（界面观察） | 官方 API 总大小最高 4GB；网页提供竖封面 3:4、横封面 4:3 | 话题、合集、位置、热点、共创、可见范围、下载权限、定时发布 |
| 小红书 | 标题按 20 字保守校验；正文 1000 字（界面观察） | 视频帧或图片封面，支持 PK 封面 | 话题、用户、章节、合集、原创声明、可见范围、定时发布 |
| 视频号 | 短标题 6-16 字；描述上限以页面为准 | 小于 8 小时、小于 20GB、至少 720p、码率不超过 10Mbps、MP4/H.264（界面观察） | 位置、合集、链接、活动、定时、原创声明、视频标注 |
| YouTube | 标题 100 字符；说明 5000 字符；标签总计 500 字符 | 缩略图推荐 16:9、最小宽度 640；上传文件限制以账号页面为准 | 播放列表、儿童内容、年龄限制、字幕、语言、许可、分类、互动、公开范围、排期 |
| X | 标准 Post 按 280 字符校验 | 视频限制随账号与当前产品权限变化，不写死 | 回复权限、可见范围、定时等以页面提供能力为准 |
| TikTok | 网页描述区 4000 字符（界面观察） | 网页最大 30GB/60 分钟；推荐 MP4、1080p/1440p/4K、16:9 或 9:16；API 最大 4GB | 封面、位置、公开范围、预约、评论、Duet、Stitch、版权检查 |

## 校验原则

- 字符限制按 Unicode 字符数量进行预检，但平台最终计数可能把链接、表情或组合字符按不同方式处理。
- 平台页面显示的账号级限制优先于静态规则。
- TikTok API 必须先调用 Query Creator Info 获取当前账号最大时长和可用隐私级别。
- X 视频规格和费用变化频繁，只做基础文件存在性与通用编码检查。
- 封面没有明确官方尺寸时，只校验平台要求的比例，不伪造精确像素要求。
